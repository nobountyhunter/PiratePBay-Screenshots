**ThePBay Screenshots**

A small, free and open-source browser extension that shows screenshot links right on the page — no need to open each link one by one.

**Install (Chrome / Edge / Brave):**

1. Download the files into one folder (extract the `.zip` first if needed).
2. Open `chrome://extensions`.
3. Turn on **Developer mode** (top-right).
4. Click **Load unpacked** and select the folder with `manifest.json`.
5. Done.

**Firefox:** `about:debugging` → **This Firefox** → **Load Temporary Add-on** → pick `manifest.json`.

Open source — all code included, nothing hidden.
